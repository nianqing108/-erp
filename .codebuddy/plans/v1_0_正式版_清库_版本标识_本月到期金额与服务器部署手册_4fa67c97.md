## 产品概述

简易ERP v1.0 正式版发布准备：清理演示数据空库上线、统一版本标识为 v1.0.0、仪表盘新增「本月到期金额」指标，并交付一份面向 Linux + Docker 服务器的完整部署手册（同时回答数据库选型问题）。

## 核心功能

- **数据清理**：正式库保持空库上线（init.sql 仅建表无种子数据）；H2 演示实例数据随重启清空；sample-data.sql 保留在仓库但不在任何部署路径导入；README 调整导入说明为「仅本地试用可选」
- **版本标识 v1.0.0**：登录页副标题、系统顶栏显示 v1.0.0；README 标题标注；前后端 package/pom 版本核对为 1.0.0
- **本月到期金额**（新指标卡）：应收欠款中约定收款日（dueDate）落在本月（月初~月末）的未收余额合计；未填约定收款日的订单无法判定到期日，不计入（页面注明口径）
- **部署交付**：docs/07 重写为「从零部署到 Linux 服务器（Docker Compose）」完整上手手册；README 增加数据库选型说明（生产 MySQL 8.0 容器内置，H2 仅本机演示）

## 技术方案

### 1. 本月到期金额（后端）

- `DashboardService.overview()` 已持有 `List<DebtRowVO> debtRows`（含 dueDate/balance），**无需新增 SQL**：Java 侧过滤 `dueDate != null && dueDate 在本月(YearMonth.now())`，累加 `nonNegative(balance)`，O(n) 复用现有一次取数
- `DashboardVO` 新增 `monthDueAmount` 字段（BigDecimal，2 位小数）

### 2. 指标卡（前端）

- `Dashboard.vue` 指标卡：新增「本月到期金额」（插在应收欠款之后，副标题“约定收款日在本月的未收余额”），移除「客户总数」保持 6 卡 3×2 网格
- `types/index.ts` DashboardVO 同步 `monthDueAmount`、移除 `customerCount`

### 3. 版本标识 v1.0.0

- 登录页副标题加 `v1.0.0`；顶栏右侧 tag 显示 `v1.0.0`
- README 标题标注 v1.0.0；核对 pom.xml / package.json 均为 1.0.0（已一致则仅确认）

### 4. 数据清理

- 无需改 init.sql（本就无种子数据）；README 中 sample-data.sql 导入说明改为「仅本地试用可选，正式部署不导入」；compose 未挂载该文件，天然不会进入正式库
- 停止本机 H2 演示后端进程（演示数据随之消失）

### 5. 部署手册（docs/07 重写为从零上手）

- 数据库回答：生产 MySQL 8.0（compose 内置容器，免安装）；H2 仅本机无 MySQL 演示用，数据不持久
- 步骤：装 Docker+Compose → 上传代码（git/scp）→ `cp .env.example .env` 改 DB_PASSWORD/JWT_SECRET/REGISTER_CODE → `docker compose up -d --build` → 安全组放行 80 → 注册登录验证 → cron 配置备份 → 后续更新发布流程
- 附：数据持久化（mysql-data 卷）、日志位置、常见问题（端口占用、改密后重登）

### 性能与兼容

- 本月到期金额复用现有取数，无新增查询；`dueDate` 为空不计入的口径在卡片副标题与文档明示，避免歧义
