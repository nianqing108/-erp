# 08 用户操作手册（业务人员版）

登录后左侧菜单共 5 个页面。所有金额单位为元。

## 1. 仪表盘

打开即见的经营总览，数据实时统计，无需操作：

- **指标卡**：未发货金额 / 本月订单额 / **应收欠款**（唯一计欠款的口径）/ **本月到期金额**（约定收款日落在本月的未收余额，没填约定收款日的订单不计入）/ 未到期金额（约定收款日还没到的部分）/ 本月回款 / 累计已收 / 客户数
- **逾期账龄分布**：应收欠款按**约定收款日**起算逾期天数，分未到期 / 逾期 0-30 / 31-60 / 61-90 / 90 天以上五档，颜色由橙到深红递进；没填约定收款日的订单按发货日起算
- **欠款 Top 客户**：欠款最多的客户排行，超过信用额度的客户红色高亮

## 2. 客户管理

- **新增客户**：右上角「新增客户」，公司名称必填且不能重复；信用额度填 0 表示不限
- **查欠款**：列表「当前欠款」列即为该客户实时应收；超额客户标红并带「超额」标签
- **看账**：点行内「对账单」直接跳到该客户的对账页面
- **删除**：仅无任何订单的客户可删（防止账目失去归属）

## 3. 订单管理

### 3.1 新建订单
点「新建订单」：选客户、填下单日期与金额；**内部订单号由系统自动生成，不用手填**；「客户订单号」选填，是客户给你的原始单号（PO 号），方便日后对账检索。

### 3.2 订单的一生（状态标签颜色固定）

```
录入(灰) → 确认发货 → 待付款(蓝) → 已完成(绿)
   └────────── 取消(红) ──────────┘
```

订单行的操作按钮按状态自动出现，不用记规则：

| 当前状态 | 你能做的操作 | 说明 |
| --- | --- | --- |
| 录入 | 编辑 / 确认发货 / 取消 | 只有「录入」状态能改金额等字段 |
| 待付款 | 录入收款 | 可分批多次收款，收满自动「已完成」 |
| 已完成 / 已取消 | 仅查看详情 | 无可执行操作 |

> 注意：
> - 发货是**一步操作**：点「确认发货」填实际发货日与物流单号，订单直接进入「待付款」并计入欠款
> - **发货之后就不能取消了**，取消仅限未发货的「录入」状态

### 3.3 收款
点「收款」填本次金额与到账日期。系统实时提示未收余额，**超收会被拒绝**；最后一笔收清时订单自动变为「已完成」。

### 3.4 查找订单
顶部筛选：状态 / 客户 / 内部订单号 / 客户订单号 / 下单日期区间。

## 4. 客户对账单

选客户 + 对账区间（默认本月）后：

- **四格汇总**：期初欠款、本期发货额、本期回款额、期末欠款（期末 = 期初 + 本期发货 − 本期回款）
- **明细**：区间内每笔发货订单，展开行可见该单的每笔收款
- 点「导出 Excel」可下载发给客户核对

## 5. 月度报表

- 顶部切换月份，四个指标卡：订单量、出货量、回款金额、订单完成率
- 趋势图展示近 12 个月对比（柱=单量，线=回款）
- 点「导出 Excel」留存
