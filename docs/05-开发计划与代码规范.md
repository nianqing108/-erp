## 代码规范

### 后端（阿里巴巴 Java 开发手册裁剪版）

- 分层职责：Controller 只做参数接收与 `Result` 封装；**Service 是唯一事务边界与业务规则落点**；Mapper 只做数据访问
- 金额一律 `BigDecimal`，禁止 `double/float`；统一经 `MoneyUtil` 归一（2 位小数、非负、比较）
- 状态流转必须走 `OrderStatus` 枚举的 `canXxx()` 方法，禁止字符串散落判断
- 统一异常：业务错误抛 `BusinessException`（WARN 日志、code=400/409），系统异常由 `GlobalExceptionHandler` 兜底（ERROR 日志）
- 统一日志：SLF4J 占位符写法，禁止字符串拼接；禁止打印客户完整手机号

### 前端

- API 层统一走 `src/api/request.ts`（自动解包 `Result<T>`、统一错误提示），组件内不直接 import axios
- 金额展示统一 `money()`（千分位 + 2 位小数），状态标签统一 `STATUS_META` 语义色
- 视图按路由懒加载；设计令牌（颜色/圆角/阴影）集中在 `src/style.css`

## Git 提交规范

Conventional Commits：`feat:` `fix:` `docs:` `test:` `refactor:` `chore:`；一个迭代结束在 `main` 打 tag（`v1.0.0`）。
